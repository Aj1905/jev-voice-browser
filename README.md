# Jev Voice Browser

音声でブラウザを操作する Chrome 拡張機能。発話の解釈は TypeSafe の **Jev**(System One モデル)が担当します。

## しくみ

1. サイドパネルで Chrome の音声認識 (Web Speech API) が発話を文字にする
2. ページ上に見えている操作可能な要素(最大 150 個)を集めて番号を振る
3. Jev に 1 回だけ問い合わせ、次の質問を並列に答えさせる
   - `action` (Choice): スクロール / クリック / 入力 / Web 検索 / 戻る / タブ操作 …
   - `target` (Choice): どの要素か(要素一覧 + 「ここ」= マウスカーソル下の要素)
   - `scroll_amount` (Choice): 少し / 1 画面 / たくさん
   - `submit` (Noul): 入力後に送信するか
   - `text` (Choice): 入力・検索する文字列の候補(コード側で発話から切り出したもの)のどれか
4. 確信度が設定値未満なら実行せず聞き直し、そうでなければ実行する

Jev は文章を生成しないモデルなので、「入力する文字」はコード側で候補を作って Jev に選ばせています。
「5番」のような番号指定はコード側で確定させます。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオン
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
3. 拡張機能のアイコンをクリック → サイドパネルが開く
4. 「設定」で TypeSafe の API キー(https://typesafe.ai で発行)を入れて保存、「接続テスト」
5. マイクボタンを押す。初回はマイク許可のタブが開くので「許可」

## 使い方

- マイクボタン、または **Alt+Shift+V** で音声入力の開始 / 停止
  (ショートカットは `chrome://extensions/shortcuts` で変更可)
- 「聞き続ける」をオンにすると、話すたびに操作を続けて実行。「ストップ」で終了
- 「番号を表示」をオンにすると、ページ上の要素に番号が出るので「7番をクリック」と言える
- 「ここクリックして」は、マウスを 0.25 秒以上止めていた位置の要素が対象。
  サイドパネルのボタンを押しに行くとマウスが動いてしまうので、ショートカットか「聞き続ける」と組み合わせるのがおすすめ
- テキスト欄に文字で指示を打つこともできる(動作確認用)

話し方の例:「スクロールして」「もっと下」「一番上へ」「ログインを押して」「検索欄に東京の天気と入力して検索」「猫の飼い方を検索して」「戻って」「次のタブ」「このタブを閉じて」

## 制限

- Jev は日本語の精度が英語より低め(公式ドキュメントより)。確信度が低いと実行しないので、その場合は言い方を変える
- クリックや Enter は DOM イベントの合成なので、一部のサイト(isTrusted を見るもの)では効かないことがある
- iframe の中・Shadow DOM の中の要素は対象外
- `chrome://` ページや Chrome ウェブストアではページ操作不可(戻る・タブ操作・Web 検索は可)
- 音声認識は Chrome の機能で、音声は Google のサーバーに送られる
